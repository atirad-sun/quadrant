# Quadrant To-Do

A playful to-do list built around the **Eisenhower matrix**: drag tasks into Do First, Schedule, Delegate or Eliminate.

**▶ Use it here: https://atirad-sun.github.io/quadrant/**

- Free, with no sign-up.
- Works offline, and you can install it to your home screen or dock.
- **Your tasks never leave your device.** They're saved in your browser, and nothing is sent to a server. Use ⋯ → Export backup to keep a copy or to move your tasks to another device.
- Quick-add codes: `!1`–`!4` pick a box, `#tag` adds a category, `@tmr` / `@fri` / `@3d` set a deadline, and `@weekly` / `@every-mon` make the task repeat.
- Keyboard: arrow keys move between cards, `1`–`4` / `0` move the selected card, `N` adds a task, `/` searches, `V` switches the layout.

The whole app is a single HTML file, with no frameworks and no tracking.
